# Sports Intelligence Hub

Sports Max Master Prompt:

MASTER PROMPT — SPORTS MAX SPORTS ANALYTICS PLATFORM

1. Project Overview

Build a modern, professional, responsive web platform called SportsMax focused on Sports Analytics and Athlete Performance Intelligence.

SportsMax should provide a digital presence for sports analytics while integrating a Run Analytics App that helps athletes track running performance, understand their performance data, view analytics dashboards, and receive actionable recommendations.

The website should communicate the complete journey:

Capture → Analyze → Understand → Automate → Improve

The platform should serve:

•	Athletes

•	Coaches

•	Sports communities

•	Fans

•	Sports organizations

•	Performance analysts

The website must feel like a real sports technology and analytics product, not a generic sports blog or ordinary fitness website.

________________________________________

2. Primary Objective

Create a digital platform that demonstrates how SportsMax transforms raw sports and running data into meaningful performance intelligence.

The platform should:

1.	Capture athlete and running data.

2.	Analyze performance data.

3.	Generate meaningful performance insights.

4.	Present analytics through interactive dashboards.

5.	Automate recurring analytics and reporting.

6.	Provide recommendations based on athlete performance.

7.	Enable engagement between athletes, coaches, fans, and sports communities.
